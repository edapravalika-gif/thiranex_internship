# Data Cleaning & Reporting Automation

## Objective
Automate common data preprocessing tasks and produce a cleaned CSV, a text summary report, and a chart.

## Project files
- `data/customer_data_raw.csv` — sample raw customer data with duplicates, missing values, inconsistent spaces, and invalid entries.
- `automate_report.py` — Python automation script.
- `outputs/customer_data_cleaned.csv` — cleaned output generated by the script.
- `reports/automated_summary_report.txt` — generated summary report.
- `reports/customers_by_city.png` — customer count chart.

## Requirements
Python 3.9+ recommended, plus:
```bash
pip install pandas matplotlib
```

## Run
From this project folder:
```bash
python automate_report.py
```
The script reads the sample data, cleans it, writes the output files, and prints a summary to the terminal.

## Cleaning steps
1. Trims text fields.
2. Converts numeric columns and dates.
3. Removes exact duplicate rows.
4. Flags impossible ages and treats them as missing.
5. Fills missing numeric values with medians.
6. Fills missing names/cities and invalid dates with `Unknown`.
7. Produces a text report and city-count bar chart.

## Notes
This is a sample educational project. The dataset is synthetic and does not contain real customer information.
